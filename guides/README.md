# Guides

One guide per skill, at `guides/<area>/<skill-name>.md`. Each guide explains what the skill does, how it works, how to install and test it, how to use it day to day, and how to fix common problems.

Guides are listed with their skills in the [main README](../README.md#skills) and in each area's README. To write one, start from [`templates/guide-template.md`](../templates/guide-template.md).
